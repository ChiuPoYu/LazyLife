# LazyLife
2026 YTP 黑客松 - 以最人性化、最精準的方式知道你想去哪玩

LazyLife is an open-source AI collaboration engine that transforms group conversations into structured decisions.

## It enables:

- Automatic discussion summarization

- Group voting and decision tracking

- Shared itineraries and notes

- Government open data integration

## Vision

Build the first open-source AI platform focused on group intelligence, not just chat.

## Architecture

Modular Monolith (.NET Core)

Hexagonal Architecture

Python AI Engine (NLU / RAG / Stats)

Plugin-based extensibility
